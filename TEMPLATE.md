# Template provenance

Adapted from [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template)
by Eliahu Horwitz, itself adapted from [Nerfies](https://nerfies.github.io/).
Source commit: `d38af1ccae1ce82c3404d2820c4c646afd409f81`.

The template hero, teaser, abstract, section and footer structure and its
`static/css/index.css` are retained. Project content, responsive task navigation,
results, local media, and an additional theme stylesheet are added.
Author metadata, placeholder links, external fonts, analytics, jQuery, Adobe
embeds, and unused carousel/icon dependencies are removed.

Bulma 0.9.1: MIT, original notice retained in its stylesheet. Research code on
main: GPL-3.0-only. The manuscript and research media retain their original
rights; the template license does not relicense third-party footage.
